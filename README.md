# Spirit Dragon · public landing page

Static marketing website for Spirit Dragon by MinnyMedia. Published separately from the game; this repository contains only public website files and optimized marketing artwork.

Public URL: https://myguitarmethod.github.io/Spirit-Dragon-landing/

## Launch preparation

“Available on Google Play” is launch-ready wording requested by the developer. A public Store listing was not accessible during preparation. No download button or placeholder Store URL is included. Add the developer-supplied, verified public listing at launch.

## Content and assets

- Features checked against the Android game's current source: Easy/Normal, six dragons, four power-ups, score progression, 38 achievements, four leaderboard categories and Ancient Rites.
- Images are optimized exports of original Spirit Dragon branding, dragon portraits and the six official mobile Store screenshot panels. Gameplay panels retain their promotional captions; older screenshot UI may differ from the latest release. They are not newly generated gameplay mockups.
- Support: ruanminny88@gmail.com.
- Privacy policy: linked to the existing public policy used by the game. The policy is maintained separately; this task did not rewrite it.
- No accounts, analytics, embedded third-party scripts, cookies or contact forms are added by this landing page. Hosting remains subject to GitHub's policies.

## Maintenance

Edit `index.html`, `styles.css` or `gallery.js`. Preserve relative asset paths for GitHub Pages. Pages publishes `main` from the repository root. No build step or runtime dependencies are required. Keep game source, Android builds, credentials and signing material out of this repository.
